# 定时任务安装

三个 launchd 任务：采集每 30 分钟一次（`ingest`），健康日报每天 18:00（`health-daily`），
周报每周日 09:00（`health-weekly`）。Mac 在计划时间休眠时，launchd 会在下次唤醒后补跑。

## 安装

把占位符替换成真实路径后装入 `~/Library/LaunchAgents/`：

```bash
VAULT="/path/to/your/vault"   # 改成你的 vault 绝对路径
for f in com.rays-brain.*.plist; do
  sed -e "s|__VAULT__|$VAULT|g" -e "s|__HOME__|$HOME|g" "$f" \
    > ~/Library/LaunchAgents/"$f"
  launchctl load ~/Library/LaunchAgents/"$f"
done
```

## 验证与卸载

```bash
launchctl list | grep rays-brain          # 应看到三个任务
launchctl unload ~/Library/LaunchAgents/com.rays-brain.ingest.plist   # 卸载某一个
```

日志在 `~/Library/Logs/rays-brain/`。没有新资料时采集任务不会调用模型，空转成本可忽略。
