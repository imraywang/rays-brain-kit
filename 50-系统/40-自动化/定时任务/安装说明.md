# 定时任务安装

四个 launchd 任务：采集每 30 分钟一次（`knowledge-ingest`），健康日报每天 18:00（`knowledge-health-daily`），
内容快照每天 18:05（`content-snapshot`），周报每周日 09:00（`knowledge-health-weekly`）。
Mac 在计划时间休眠时，launchd 会在下次唤醒后补跑。

内容快照要求 vault 本身是 Git 仓库（clone 本模板即满足）；有 `WEREAD_API_KEY` 时会先同步微信读书，没有则跳过。
不需要这个任务可以不装，健康日报会把它标为未安装但不影响其他检查。

## 安装

把占位符替换成真实路径后装入 `~/Library/LaunchAgents/`：

```bash
VAULT="/path/to/your/vault"   # 改成你的 vault 绝对路径
for f in com.ray.*.plist; do
  sed -e "s|__VAULT__|$VAULT|g" -e "s|__HOME__|$HOME|g" "$f" \
    > ~/Library/LaunchAgents/"$f"
  launchctl load ~/Library/LaunchAgents/"$f"
done
```

## 验证与卸载

```bash
launchctl list | grep com.ray             # 应看到四个任务
launchctl unload ~/Library/LaunchAgents/com.ray.knowledge-ingest.plist   # 卸载某一个
```

日志在 `~/Library/Logs/rays-brain/`。没有新资料时采集任务不会调用模型，空转成本可忽略。
